## 🔥 Features & Highlights

- **🤌 Pinch-to-Switch Filters**: Touch index finger to thumb to cycle filter presets with fingertip spark bursts.
- **✋ Organic Hand Polygon Masking**: Uses 22 hand structural landmarks to build a smooth, dynamic convex polygon mask that stretches across both hands.
- **🎨 10 Mind-Blowing Visual Shaders**:
  1. **Cyber Matrix** 🟩 — Green digital terminal code streams raining down dynamically.
  2. **Thermal Predator** 🟧 — High-contrast heat vision map with glowing orange core.
  3. **Anime Ink Sketch** ✏️ — Pure Manga B&W ink line art illustration.
  4. **Vaporwave Synthwave** 🟪 — Hot magenta/purple dual-tone split & horizon grid.
  5. **RGB Glitch Tearing** 🔴 — Chromatic channel displacement with scanline tearing.
  6. **Deep Ocean Blue** 🟦 — Deep cyan aquatic bioluminescence with floating bubbles.
  7. **Molten Gold** 🟨 — Metallic champagne gold sepia & sparkling gold dust.
  8. **Rainbow Prism** 🌈 — 360° rotating iridescent spectrum dispersion beams.
  9. **Vintage Film Noir** 🎬 — B&W grainy classic movie camera with vignette.
  10. **Acid Psychedelic** 🌀 — High-energy neon green & magenta color warp.
- **✨ Fingertip Particle Trails**: Continuous glowing embers follow all 10 fingertips in real time.
- **💥 2-Hand Clap Shockwave**: Bring hands together to launch an expanding radial energy pulse.
- **🎨 Neon Finger Light Painting**: Draw glowing neon light trails in mid-air with your index fingers.
- **⚡ Decoupled 60 FPS Performance Engine**: AI detection paced at 65ms intervals for 60.0 FPS smooth screen rendering.
- **🎛️ High-Tech Glassmorphic Control Panel**: Sleek HUD panel inspired by TouchDesigner & `wxll.hx` with live FPS progress meter and glowing preset pills.

## 🛠️ Tech Stack

- **AI Hand Tracking**: MediaPipe Hands JS (WebAssembly)
- **Graphics & Composition**: HTML5 Canvas 2D / GPU Shaders / CSS Glassmorphism
- **Server Engine**: Node.js & Express
- **UI Design System**: Vanilla CSS Variables & Glassmorphism Blur Backdrop

## 🚀 Local Setup & Running

```bash
# Clone the repository
git clone https://github.com/SIDDHUguts/quantum-window.git

# Navigate into directory
cd quantum-window

# Install dependencies
npm install

# Start local dev server
npm start
```

Open `http://localhost:3000` in your browser!
